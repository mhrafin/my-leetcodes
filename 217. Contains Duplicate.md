# First Solution
```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        return len(set(nums)) != len(nums)
```

## Explanation
To explain why this works, we need to know what `set()` does. `set()` cannot have duplicates. Duplicate values will be ignored. So if we create a set of the `nums` List and the length of both stays the same, that means there was no duplicate value. And if after they differ then there was a duplicate value.
